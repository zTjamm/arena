# Арена

Арена на выталкивание: восемь героев на квадратном поле, выиграть
может только тот, кого **толчком** вынесли за край. Ходьбой за границу
не выйти — граница просто прижимает.

## Что это

- **Толчок с зарядом.** Кнопку надо **держать**: 1 секунда — отлёт на
  100 единиц, 2 — на 200, 3 и больше — на 300. Удар уходит при
  отпускании. Бьётся только ближайший в конусе; если он влетел в
  другого, тот отлетит на половину удара, а первый остановится.
- **Прыжок** ровно на 300 единиц, всё это время неуязвим.
- **Камень** на 2 секунды: удар от него отскакивает — бьющий летит на
  половину своего удара. Камень при этом **абсолютно неподвижен**: его
  нельзя сдвинуть ни ходом, ни выжиманием, ни налетевшим телом.
- **Перезарядки** — три звезды над героем: синяя, золотая, коричневая.
  Звезда заполняется снизу вверх, готовая мигает. Заряд толчка виден
  ещё и кольцом вокруг героя, с засечками на границах ступеней.
- **На телефоне и планшете — боком.** Пока видимая область вертикальная,
  поле закрывается заслонкой «поверните устройство».

## Проверки

248 проверок: `npm test`. Боты прогоняются на тысяче партий на двоих и
по сотне на тройке, пятёрке и восьмёрке — на случай, если правка

## Размещение

Арена живёт **по пути `/arena/`** на домене, где уже стоят «Точки и
квадраты»:

| адрес | что открывается |
|---|---|
| `https://mypoddomenjm.mooo.com/` | «Точки и квадраты» — как и раньше, не тронуто |
| `https://mypoddomenjm.mooo.com/arena/` | арена |

Из этого вытекли два требования к коду, оба неочевидные:

- **Пути к скриптам в разметке относительные.** Абсолютный `/bundle.js`
  со страницы `/arena/` попал бы в корень домена и обслуживался чужой
  игрой: страница арены грузила чужие скрипты и получала 404. Проверка
  на это стоит в `deploy.sh` и валит деплой.
- **Путь сокета выводится из адреса страницы** (`BASE` в
  `public/app.js`), а на сервере задаётся `SOCKET_PATH=/arena/socket.io`.
  Иначе сокет ушёл бы на `/socket.io` — тоже в чужую игру.

### Деплой

```bash
ssh root@89.125.54.41 '/root/arena/deploy.sh'
```

Скрипт бэкапит конфиг nginx, **встраивает** арену в существующий
доменный блок (отдельным файлом это не сделать: директива `location` на
верхнем уровне не допускается, `nginx -t` падает), гоняет тесты, и
только потом перезагружает nginx. Если конфиг невалиден, перезагрузки не
происходит и скрипт откатывает файл — старая игра продолжает работать.
В конце скрипт проверяет, что корень с крестиками тоже отвечает: молчать
об успехе арены, пока крестики лежат, нельзя.

Отдельный процесс PM2 с именем `arena` на порту 8100. Процесс
`tic-tac-toe` не перезапускается и не меняется.

## Запуск

```bash
npm install
npm start     # http://127.0.0.1:8100
npm test      # 248 проверок
npm run view  # http://127.0.0.1:8200 — просмотрщик ботов без сервера
```

## Устройство

| файл | что в нём |
|---|---|
| `game/arena.js` | симуляция: поле, три скилла, столкновения, граница, места |
| `game/bot.js` | боты, те же входы, что и у людей |
| `game/lobby.js` | подбор: комната, окно набора, состав — без часов |
| `accounts.js` | аккаунты, вход, рейтинг, друзья — без сокетов и часов |
| `server.js` | сокет, сессии, чат, тик партии, начисление очков |
| `public/heroes.js` | восемь героев: цвета и отличительные детали |
| `public/hero-draw.js` | рисование героя и вылетающей руки |
| `public/render.js` | общий рисовальщик: поле, прицел, звёзды, анимации |
| `public/app.js` | экраны авторизации и чата, сокет, друзья, комната |
| `public/client.js` | партия: ввод, отставание, кадры, результат |

Ядро — чистый модуль без сети и без графики, поэтому его можно гонять
тысячами партий в тестах. Для браузера те же файлы собираются в
`public/bundle.js` (`node tools/bundle.js`) и правятся только в `game/`
и `public/`, не в бандле.
